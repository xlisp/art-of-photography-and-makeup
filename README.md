# 摄影与化妆的艺术

> 基于实战笔记整理的摄影与人像美学指南。核心理念：**有限表现无限**，用合适的光影突出优点、弱化缺点。

---

## 一、拍摄数量哲学

- **多拍摄，快速连拍多张**，总能捕捉到一两张不错的
- 尤其是热身阶段，多拍一些普通的，慢慢就会找到感觉、熟悉环境、发现美

## 二、构图：有限表现无限（美术原则）

- 脚尖顶框框、或者只拍丝袜一小节，能表现更高、更多想象空间
- 拍摄时，**人要蹲下去拍才行**
- 侧身正脸会显得很瘦

## 三、色彩：高反差美术原则

- 衣服全身不要超过三种颜色，看搭配才行
- 单个上衣或单个裤子都无法表现美，**搭配好了才有效果**
- 衣服主色与背景高反差：如白色衣服配绿色叶子 —— 一战封神，摄影大师之作

## 四、画面比例

- 不能天空太多，也不能地面太多
- **中心焦点**最多使用
- 其次左右偏焦点，突出景色并绕开路人

## 五、取景器与构图发现

- 用眼睛先发现美的构图后，马上用**单反取景器**确认，测试拍几张，然后再正式拍
- 手机很难匹敌**大底虚化**的单反；别用手机
- iPad 取景框比手机更大，更好瞬间捕捉到
- 发现美的时候，马上拍下来看看
- 取景时，多试几个焦距，找最佳构图

## 六、角度探索

- 经常对方正在一块，**各种角度**都试一遍，找到最美的那个
- 比如侧脸美，还是冷酷笑起来美 —— 就以这个最美脸型为主

## 七、单反基础使用

- 晚上拍照注意带单反**支架**，不然抖动就糊了
- **P 挡**最多使用
- **M 挡**固定机位焦距
- **B 挡**用于天文等长曝特效，例如：
  - 与银河一起合影
  - 拿一个灯光滑动，形成形状长曝合影

## 八、光线：合适的光影突出优点、弱化缺点

- 晚上拍摄需要测试白平衡，拍出来效果不对可能要重新设置
- 晚上有时候用屏幕预览模式，可以出更好的效果
- 发现光线不对时，可用闪光灯方式补光，或去掉灯光减光

**好的光线：**
- 天气晴朗时，太阳光不会曝晒的**阴凉处**
- **夕阳**的时候，很容易出大片
- 匀色单色光：如博物馆、室内灯光设计较好的地方

> 光影帮助突出优点、减弱缺点 —— 必要加上后期处理

## 九、人的状态

- **摄影师和模特的心情**都很好、环境优美、天气好，特别容易出大片

## 十、构图搭配

- 和什么远景构图在一起更好、背景虚化什么背景更好
- 高或低的背景和人构图在一起

## 十一、原片与后期

- **原片好才是真的好（80%）**
- 后期只是很小的一部分（10%）
- portraiture、美图秀秀等：去皱纹、痘痘等修饰

---

## 核心要点速记

| 维度 | 关键 |
| --- | --- |
| 数量 | 多拍、连拍 |
| 构图 | 有限表现无限，蹲下拍 |
| 色彩 | 高反差、三色以内 |
| 比例 | 中心焦点，避开天/地过多 |
| 工具 | 单反 + 大底虚化 + 支架 |
| 光线 | 阴凉处 / 夕阳 / 匀色单色光 |
| 心境 | 摄影师与模特状态都好 |
| 原片 | 80% 看原片，10% 看后期 |
